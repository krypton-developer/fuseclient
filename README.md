# Fuse Client

A clean utility client for **Minecraft 1.21.11** (Fabric). Fuse is **free**: log in with Discord and download.

**Get Fuse:** https://dashboard.fuseclient.com  
**Website:** https://fuseclient.com  
**Discord:** https://discord.gg/um7saN5vjh

> This repo holds guides and the place to report bugs. There is no source code and no download here.
> Fuse is only ever downloaded from **dashboard.fuseclient.com**. Any other download is not Fuse.

## Get started

1. Go to https://dashboard.fuseclient.com and click **Connect Discord**. Fuse only sees your Discord name and profile picture.
2. Click **Download** to get your Fuse jar.
3. Install Fabric for 1.21.11, put **Fabric API** and the **Fuse jar** in your `mods` folder.
4. Start the game and press **Right Shift**.

Full steps: [docs/INSTALL.md](docs/INSTALL.md) · Questions: [docs/FAQ.md](docs/FAQ.md) · Staying safe: [SECURITY.md](SECURITY.md)

## What's in it

- Around 100 modules in Combat, Movement, World, Base Finding, Visuals, Automation, Utility, HUD and more
- A Right Shift menu in three layouts (Dropdown, Panel, Wheel) and five styles
- Themes, colours, roundness and sounds
- A HUD editor to move things on screen
- Configs: save, share with a short code, browse public configs, cloud configs that follow you to any PC
